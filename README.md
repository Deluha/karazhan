# Project Karazhan

A local-first knowledge library: it indexes the documents you already have into one SQLite file and answers
questions with ranked, cited passages, from a command line, a Python API and an MCP server. Nothing is built
yet; the planned scope is in [`ROADMAP.md`](ROADMAP.md).

Project Karazhan is an independent open source project, named after the legendary raid as an homage. It is
not affiliated with or endorsed by Blizzard Entertainment, and it has nothing to do with World of Warcraft.
